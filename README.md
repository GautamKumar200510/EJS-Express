# EJS-Express

A beginner-friendly practice project built with **Node.js, Express.js, and EJS** to understand server-side rendering, Express routing, and working with dynamic data using EJS templates.

---

## About The Project

This project was created to practice and understand the fundamentals of:

- Node.js
- Express.js
- EJS (Embedded JavaScript Templates)
- Server-Side Rendering
- Express Routes
- Dynamic HTML rendering
- Working with JSON data
- Basic project structure in Express applications

The project uses **EJS templates** to generate dynamic HTML pages from server-side data.

---

##  Technologies Used

| Technology | Purpose |
|------------|---------|
| Node.js | JavaScript runtime |
| Express.js | Backend web framework |
| EJS | Template engine |
| JavaScript | Application logic |
| JSON | Data storage |
